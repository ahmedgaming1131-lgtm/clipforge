# ClipForge AI — URL-to-Clips

الصق رابط فيديو عام ومسموح تنزيله، وسيحاول التطبيق جلبه ثم تفريغ الكلام واستخراج كليبات قصيرة مع كابشن.

## النشر

1. أنشئ حسابًا على Hugging Face.
2. أنشئ Space جديدًا واختر Docker.
3. ارفع `app.py` و`requirements.txt` و`Dockerfile` إلى المستودع.
4. انتظر اكتمال البناء وافتح رابط Space.

## حدود مهمة

- لا يوجد رابط عام جاهز قبل نشر المشروع على حساب استضافة.
- يدعم روابط ملفات الفيديو المباشرة، كما يستخدم yt-dlp لمصادر عامة يسمح مالكها بالتنزيل.
- لا يتجاوز DRM أو تسجيل الدخول أو صلاحيات الفيديوهات الخاصة.
- الحد الأقصى للتنزيل التجريبي 700MB.
- الاستضافة المجانية قد تكون بطيئة أو تتوقف عند عدم الاستخدام.
- تتم معالجة الفيديو على خادم الاستضافة؛ لا تستخدم روابط خاصة أو محتوى لا تملك حق استخدامه.
- أول تشغيل قد ينزّل نموذج Whisper.
- اختيار المقاطع يعتمد على مؤشرات نصية وكثافة الكلام. تتبع الوجه والتحليل الدلالي المتقدم غير موجودين بعد.
- تنزيل روابط الإنترنت من خادم عام يتطلب ضوابط أمنية إضافية قبل إطلاق تجاري؛ لا تنشر الخدمة للعامة دون إضافة حماية SSRF ومعدلات طلب وحدود موارد أقوى.
